# Workflow V2 Implementation Plan

**Goal:** 在保留 V1 的基础上提供支持多节点、变量引用和条件分支的内存运行时。

**Architecture:** contracts 导出独立 V2 schema；engine 提供结构/拓扑校验、节点注册表、串行 DAG 调度、隔离的运行上下文与事件回调。边的 active/skipped 状态决定汇合节点是否执行；运行只消费单次解析快照。

**Tech Stack:** TypeScript、Zod、Vitest。**Spec:** `docs/superpowers/specs/2026-11-08-aiflow-design.md`。

## 范围和验证

1. V2 草稿只做结构解析；执行图额外验证唯一 ID、端口、入出边、环、可达性和上游引用。V1 保持不变。
2. 开始节点输出输入；转换节点按名称解析字面量或上游输出；条件节点根据布尔引用选择 true/false；结束节点解析输出映射。
3. 按依赖顺序串行运行；边决议后，全跳过的节点跳过并传播，至少一条有效入边的汇合节点运行。缺失引用为明确失败。
4. 返回运行及节点状态、时间、结构化错误；回调失败不能影响执行；支持运行前或节点间取消，不承诺中断自定义执行器。
5. 测试协议、图、节点调度、分支汇合、失败、取消、快照与兼容性；应用层、外部 I/O 和持久化不在本计划范围。

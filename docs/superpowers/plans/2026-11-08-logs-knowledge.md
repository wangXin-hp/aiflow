# 运行日志与知识库基础计划

**目标：** 增加结构化、默认不记录数据内容的运行日志，并建立切分、向量入库和检索的可组合能力。

**设计：** 引擎日志分为运行和节点开始/结束，含运行 ID、节点类型、耗时、状态及错误码；回调失败不影响执行。切分器提供 UTF-16 偏移、重叠与 Markdown 标题元数据；向量存储使用稳定业务 ID、显式集合维度及带知识库范围的删除过滤。写入前完成向量化校验，失败时不清理既有数据；索引与删除不承诺跨请求原子性。

**验收：** 日志覆盖成功、失败、取消和敏感信息；切分覆盖边界和 Unicode；Qdrant 请求与完整索引/检索使用模拟服务测试。真实豆包向量接口、Qdrant 部署另行联调。
